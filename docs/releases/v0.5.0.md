# Protocol Sentinel v0.5.0 — Portable Direct Integration

Status: release candidate documentation.

## Purpose

Move from repository-specific authority regression
experiments to a reusable external Foundry workflow.

## Added

- Portable Direct EOA/UUPS runner.
- Tracked TOML producer configuration.
- Fresh external Foundry execution and capture.
- Source input and compiler build provenance.
- Independent Python classification replay.
- Independent solc 0.8.24 recompilation.
- Atomic publication of verified Evidence.
- Explicit CI policy: PASS / BLOCK / REVIEW.
- Trusted GitHub CI policy binding.
- Independent external Treasury consumer integration.

## Verified externally

The separate protocol-sentinel-consumer repository
demonstrates:

- A safe upgrade retaining the declared restriction.
- An unsafe upgrade introducing an authority violation.
- Independent replay matching the Solidity classification.
- A real GitHub Actions policy gate.
- Detection of a substituted CI workflow by a separately
  required workflow-integrity check.

These tests demonstrate the supported integration path.
They are not evidence of general security coverage.

## Compatibility

Existing public Solidity APIs are retained.

The portable runner currently supports Direct EOA/UUPS
only. Existing Timelock functionality remains separate.

Evidence replay does not authenticate EVM execution.
