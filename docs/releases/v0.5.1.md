# Protocol Sentinel v0.5.1 — Portable CI & Developer Experience

v0.5.1 improves the portability checks and GitHub CI
experience introduced in v0.5.0. It does not add new
authority routes or change classification semantics.

## Changes

### External integration coverage

Sentinel CI now runs a pinned independent Treasury
Foundry consumer against the Sentinel revision under test.

The integration verifies three cases:

- Safe upgrade: STILL_SATISFIED -> PASS.
- Authority regression: CHANGED_TO_VIOLATION -> BLOCK,
  with completed verified Evidence.
- Failed producer: rejected without new completed Evidence.

### Earlier setup diagnostics

The portable runner checks its Python version, Forge
availability, and required clean Git dependencies before
creating an Evidence run.

Foundry may install solc during the initial producer build.
The verifier then requires exact solc 0.8.24+commit.e11b9ed9
for independent compiler replay before publication.

### GitHub reporting

The reference Treasury consumer publishes a readable
GitHub Job Summary and downloadable Evidence artifacts.
A verified security BLOCK still exposes its Evidence.
Technical failures retain diagnostic logs without
publishing unverified completed Evidence.

## Supported scope

The portable runner supports one declared Direct EOA/UUPS
upgrade-authority scenario per invocation. The current
build provenance requires pinned Git submodules at:

- lib/forge-std
- lib/openzeppelin-contracts
- lib/openzeppelin-contracts-upgradeable

Alternative layouts and the separate Timelock route are
not supported by this portable Direct entry point.

Independent replay confirms consistency of the recorded
classification and compiler outputs. It does not
independently authenticate EVM execution or prove that
all privilege paths have been covered.

## Compatibility

No change to public Solidity APIs, comparison semantics,
Evidence 1.0 schema, or CI decision mappings.

Install the pinned `v0.5.1` release to use the early
preflight checks. The previous `v0.5.0` tag remains
available for reproducibility.
