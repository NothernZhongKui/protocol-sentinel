# Protocol Sentinel v0.4.1 — Authority Regression

## Overview

Consolidated experimental release covering the
v0.4-A, v0.4-B, v0.4-C and v0.4.1 development cycle.

This is the first published release of the v0.4 series.

- Before/after authority regression comparisons.
- Direct EOA / canonical UUPS execution scenario.
- Pure evaluation and comparison.

## Compatibility

The existing AuthorityProbe public Solidity API is
retained. Comparison and Timelock interfaces are
additional experimental APIs.

Legacy witness schemas 0.2, 0.3 and 0.4 remain
separate from Comparison Evidence 1.0.

This release does not add arbitrary execution routes,
automatic permission discovery or live-chain monitoring.

## Security boundary

This is an experimental Foundry helper library,
not a production security scanner or audit.

Successful classification replay does not
authenticate recorded EVM execution.

Compiler reproducibility establishes agreement
of normalized compiler outputs, not execution
provenance or an externally signed build attestation.

Evidence execution provenance remains UNAUTHENTICATED.

A policy PASS applies only to the declared
actor, action and tested scenario.
