# Protocol Sentinel v0.6.0 — Release candidate review

Status: **review candidate, not a release**. PR [#41](https://github.com/NothernZhongKui/protocol-sentinel/pull/41) remains draft. No tag or merge should be made before final architecture/security review.

## Scope

v0.6 adds a **separate** Direct EOA/UUPS pipeline for existing Git-pinned Foundry workspaces, including nested workspaces in monorepos. It is not a general Solidity analyzer or a new authority route.

| Boundary | v0.6 behavior |
| --- | --- |
| Execution | Fresh, uniquely selected Foundry producer, baseline and upgraded observations |
| Identity | Consumer repository commit, repository-relative workspace, pinned Sentinel submodule chain, declared scenario |
| Compiler inputs | Git-owned source-unit byte hashes; tracked configs; no untracked or external inputs |
| Compiler output | Isolated original Standard JSON replay with the required solc version, strict existing normalized comparison |
| Evidence | Version 1.1, build-provenance v2, raw capture, replay report and optional trusted policy result |
| CI decision | `STILL_SATISFIED → PASS`; `CHANGED_TO_VIOLATION → BLOCK`; otherwise existing policy mapping |
| Publication | Failed producer, provenance or replay does not publish completed Evidence |
| Independent verification | Re-read completed bundle, re-attest Git inputs, replay compilation and classification, recompute policy decision |

The legacy Evidence 1.0 schema and v0.5 portable runner remain available. The v0.6 work does not change Solidity comparison semantics.

## Review targets (in order)

1. **Trusted policy boundary:** `scripts/trusted_workspace_gate.py`, `scripts/run_workspace_direct.py`, `scripts/verify_workspace_run.py`. A policy outside the consumer checkout is not automatically trusted: the invoking workflow must select it from a protected base. Confirm this dependency is explicit and bypass resistance is adequate.
2. **Source ownership and identity:** `scripts/workspace_context.py`, `scripts/source_closure.py`, `scripts/workspace_provenance.py`. Check nested Gitlinks, symlink resolution, workspace boundaries, ignored outputs, mutable source windows and identity collisions.
3. **Compiler reproducibility:** `scripts/replay_workspace_build.py` and `scripts/replay_build_compilation.py`. Verify that compiler version, original source-unit keys, import snapshot scope and normalized outputs cannot accidentally bless an altered build.
4. **Published Evidence contract:** `evidence/schema/comparison-1.1.schema.json`, `scripts/workspace_evidence.py`, `scripts/assemble_workspace_direct.py`. Check strict v1/v2 dispatch, raw capture losslessness, manifest-to-Evidence binding and independent revalidation.
5. **Policy decision and exit code:** `scripts/ci_policy.py`, `scripts/trusted_workspace_gate.py`, `scripts/verify_workspace_run.py`. A replay `MATCH` must never turn a `CHANGED_TO_VIOLATION` into a green process exit.
6. **Developer usability and regression:** `docs/portable-workspace-v0.6.md`, `scripts/check_capu_workspace.sh`, `scripts/check_portable_integration.sh`. Can a consumer follow the documented requirements without any Sentinel-specific hidden setup? Do Treasury and existing Direct/Timelock test paths still work?

## Deliberate limitations

- Only one declared Direct EOA/UUPS scenario per run; no discovery of unknown actors, entrypoints, roles or unsafe storage upgrades.
- Git-attested source and compiler replay **do not authenticate the original EVM execution**. The producer and its fixture are security-critical inputs.
- The workflow, branch protections, trusted policy source and compiler binary remain external trust requirements. A malicious candidate-controlled workflow can bypass a gate that repository rules do not enforce.
- Independent completed-run verification requires the matching checkout, pinned Sentinel, trusted policy and solc; it is not a standalone proof for arbitrary third parties.
- Capminal's synthetic faulty upgrade must not be presented as an upstream security finding.
- No new Timelock portable route is claimed; the pre-existing route remains separate.
